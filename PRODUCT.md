# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary: a hiring manager or small-business owner with ninety seconds, on a laptop, trying to decide if Gerhard can ship something they would actually put in front of people.

Secondary: Gerhard sending the URL in an email or WhatsApp.

## Product Purpose

A static portfolio of case studies for apps that already run in production. Success is: the visitor believes the work is real, understands the decisions, and has a reason to email.

## Positioning

Each project answers, in order: the problem, the decision, a piece of real code, what went wrong. Source stays private. Live links where they exist. This is not a GitHub résumé.

## Operating Context

Static HTML and CSS on GitHub Pages. No build step. Case studies live under `work/`. Four projects on the home page: One More Year (live pool), Vermeer Invoice (live invoice demo), Concrete Online (in build), PenTest+ Trainer (live PWA).

## Capabilities and Constraints

- No framework, no JS required for the site itself.
- Claims must be true. No invented clients, numbers, or LinkedIn URL.
- Client names only with permission. Security issues not described in exploitable detail.
- Inferred from the existing site and Gerhard's stated background (Dutch, Auckland, stock control, CEH / Security+ / PenTest+). Marked here so later work does not treat them as newly invented.

## Brand Commitments

Name: Gerhard Breukers. Voice: plain, specific, slightly dry. No hype. The work is the proof.

## Evidence on Hand

- Live apps: coffindodgerspool.duckdns.org, invoicedemo.duckdns.org, pentestplus.duckdns.org
- Captures in `media/`: one-more-year.jpg, weekly-invoice.png, concrete-online.jpg, pentest-plus.png
- Written case studies in `work/`
- Do not fabricate testimonials, traffic numbers, or client quotes

## Product Principles

1. Show the running thing before you explain yourself.
2. Case study over repository.
3. One honest problem per page.
4. Ship the site the same way the work ships: simple, on a real URL.
